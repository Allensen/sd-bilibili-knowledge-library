# 运行与输出约定

## 支持范围

0.2 首次安装入口支持 Windows 10/11 x64、PowerShell 5.1 或更新版本；普通用户无需预装 Python、FFmpeg、CUDA 或转写模型。Agent 需要允许执行本地命令、写入用户缓存和联网。Windows ARM64、macOS、Linux 尚未验收，不把理论可运行写成已支持。

设备策略自动采用 CPU INT8 中文候选，按核心数控制线程、逐条处理并检查可用内存；没有向用户展示模型或设备选择菜单。GPU 自动择优尚未实现，首版也不会下载 Whisper 权重或 GPU 依赖。多语内容由模型自动识别，实际质量验证主要为中文教程；低配电脑速度未实测。

Python 下载由固定版本 uv 负责，依赖通过 requirements.lock 的版本与哈希安装，模型压缩包和权重均校验 SHA256。Python 使用 uv 管理的上游分发，不修改系统默认 Python、PATH 或驱动。现有 Python 3.11 可复用，否则下载独立版本。

默认运行缓存位于 `%LOCALAPPDATA%/sd-bilibili-knowledge-library`；视频、原文与知识库保存在调用时明确指定的 Output 目录。它们均不写进 Skill 安装目录。多个知识库共享一份模型。模型下载完成自动删除压缩包；依赖安装禁用持久下载缓存。

若本机已有验证通过的独立运行环境，可在默认缓存目录的 runtime-location.txt 保存其绝对路径，后续无需反复传 RuntimeRoot。此文件仅留在用户电脑，不随 Skill 分发。路径失效时回到默认缓存初始化，不移动已经建立的虚拟环境。

联网源：GitHub 官方 uv 发布、Astral Python 分发、PyPI 软件包、k2-fsa 模型发布，以及 B 站接口与其媒体 CDN。不会关闭 TLS 验证或自动切换到未知镜像。连接受限时保留状态，说明哪一阶段失败，在权限或网络恢复后重试。

## Agent 命令接口

先将 Skill 绝对路径与用户输出目录填入命令。以下命令由 Agent 执行，不让用户手工配置环境。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "<skill>/scripts/run.ps1" -Action run -InputUrl "<收藏夹或BV视频链接>" -Output "<知识库目录>"
powershell -NoProfile -ExecutionPolicy Bypass -File "<skill>/scripts/run.ps1" -Action evidence -Output "<知识库目录>" -Entry "BV17N411B7Ya-p1" -Times "14,63,96"
powershell -NoProfile -ExecutionPolicy Bypass -File "<skill>/scripts/run.ps1" -Action publish -Output "<知识库目录>" -Entry "BV17N411B7Ya-p1"
powershell -NoProfile -ExecutionPolicy Bypass -File "<skill>/scripts/run.ps1" -Action doctor
```

run 是正常入口，会先取字幕，无可用字幕时才安装转写依赖和模型。evidence 只安装图像/媒体处理所需的同一组依赖，不触发语音模型下载。setup 提前准备转写环境，仅排查初始化时使用；不要在每个任务前运行 setup，免得让字幕视频也下载模型。

run 结束的 needs_notes 是交接给 Agent 写作的状态。Agent 必须继续读来源、写 article.json 并 publish，不能此时向用户声称知识库已完成。单条失败继续其他条目；最终有 failed 时进程退出码为 2，已成功条目照常可用。

同一输出目录重新 run 会刷新收藏清单，并复用同 cid 的已完成原文与哈希一致的笔记。它没有实现自动检测作者在同一 cid 下替换字幕内容的情况；用户要求重新获取时，为该条建立新的输出目录后对照更新，避免直接覆盖已核实内容。

范围：收藏夹按收藏条目数处理，一个条目只对应一个播放入口，不展开分 P 或合集。优先使用收藏接口 ugc.first_cid 对应的 P，否则默认 P1；接口 page 是分 P 总数，不是收藏时选中的 P，也不能恢复用户当时的观看位置。直接视频链接带 p 只取该 P，不带 p 默认 P1。用户明确要求全部分 P／整套课程时才传 -AllParts（Python 为 --all-parts）；显式 p 始终优先。

batch-state.json 记录 selected_video_count、selection_scope，source 记录 selection 和 available_parts。默认模式中可处理项加失败项应与去重后的有效收藏条目一致；分 P 总数只作说明。HTML 与搜索索引仅包含本次清单内的条目，历史越界输出不可自动混入。失效收藏及非视频条目记录在 unavailable 中。分页异常则停止获取并报清单不完整，不用一页结果冒充完整收藏。

CookieFile 可传入已获授权的、仅含单行 Cookie 请求头的本地文件；不会自动导出浏览器凭据。Cookie 只发往 B 站 API，不写入笔记、状态或日志，也不打包发布。没有登录权限时先处理公开可访问内容。

RuntimeRoot 用于迁移缓存或隔离诊断，不是普通用户必须选择的设置。Isolated 强制使用当前 RuntimeRoot 内新准备的 uv 与托管 Python，仅用于首次安装验证；正常执行不要添加此开关。

有些 Agent 沙箱会把 LocalAppData 重定向到临时目录。发现缓存路径落在临时沙箱、或已有运行环境突然显示未初始化时，先确认宿主提供的持久目录与文件权限；使用已验证的 RuntimeRoot，或经宿主批准在正常用户环境执行。不能通过关闭沙箱绕过授权，也不要在每个临时目录重复安装。doctor 在未初始化时只报告状态，不触发下载。

## 文章结构

Agent 完整阅读 `library/<BV-p>/source-package.json` 与需要的画面后创建同目录 article.json。所有字段中的内容均为普通文本，渲染器负责转义。

```json
{
  "transcript_sha256": "来源包给出的哈希",
  "title": "帮助读者找到视频解决的问题",
  "tags": ["主题"],
  "takeaways": ["有片段依据的要点"],
  "knowledge": [{
    "title": "知识点解决的问题",
    "explanation": "忠实于视频的说明",
    "details": ["步骤、例子或条件"],
    "source_ids": ["s001"],
    "frame_ids": [],
    "learning_tip": "可选；明确属于整理者的理解提示"
  }],
  "caveats": ["仍未核实的具体内容及时间范围"],
  "corrections": []
}
```

corrections 的每项需要 segment、before、after、frame_id、reason；当前渲染器只支持有画面证据的局部替换。frame_id 必须已经存在于 frames.json 且图片已由 Agent 查看。听辨支持但没有画面证据的改动先写成待核说明，不伪造截图依据。

publish 校验转写完成、哈希匹配、原文时间范围、知识点引用、修订片段、画面路径与证据存在，输出 note.md、entry.json、index.html 和 search-index.json。结构校验不等于事实核实，Agent 仍需核对知识点语义。

## 上游组件

本 Skill 不打包第三方二进制、模型权重或用户视频。运行时从上游下载，保留模型 LICENSE；各组件按其各自条款使用。

- [uv 安装与 Python 管理](https://docs.astral.sh/uv/guides/install-python/)
- [SenseVoice INT8 模型与下载说明](https://k2-fsa.github.io/sherpa/onnx/sense-voice/pretrained.html)
- [SenseVoice 项目与许可说明](https://github.com/FunAudioLLM/SenseVoice)
- [Sherpa-ONNX](https://github.com/k2-fsa/sherpa-onnx)
- [Faster-Whisper](https://github.com/SYSTRAN/faster-whisper)：此处仅使用随包提供的 VAD，没有下载 Whisper 识别权重。
- [PyAV](https://github.com/PyAV-Org/PyAV)：负责音频解码和截图，无需另装 FFmpeg 命令行。

尚未覆盖所有登录/风控情况、超大收藏夹以及所有平台。没有人工逐字真值，不能宣传识别准确率或“所有电脑最优”。公开分发前保留当前验收范围与这些限制。
