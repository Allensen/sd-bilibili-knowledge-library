# v0.2.1 · SD B 站收藏知识库

把来不及看的收藏整理成可阅读、可搜索、可以回看原片的本地笔记。

## 这个版本能做什么

- 给 Agent 收藏夹或视频链接，生成 Markdown 与 HTML 阅读页。
- 提炼知识点，同时保留完整转写、来源片段和视频时间。
- 有可用字幕优先使用；需要识别时按需准备 CPU 模型。
- Windows x64 自动准备独立 Python 与依赖，复用已有缓存。
- 中断后继续处理，单条失败不影响其他可处理条目。

## 0.2.1 的范围修正

- 默认只处理收藏页面上的条目入口，不自动展开整套课程。
- 直接链接指定 `p` 时，只处理指定分 P。
- 只有明确要求全部分 P 时才展开。
- HTML 和搜索索引排除不在本次清单内的旧缓存。

## 验证范围

- 既有验证：Windows x64 独立环境初始化、依赖安装与模型哈希校验。
- 既有真实案例：两条收藏按两个入口处理，产出 2 篇笔记、13 个知识点与 359 段转写。
- 发布前检查：15 项离线行为测试、Skill 元数据与格式检查、分发文件清单检查。
- 原创 HTML 演示：搜索命中、无结果提示、搜索后阅读全文、时间定位已在浏览器中检查通过，未发现控制台错误。
- 演示内容使用原创数据，展示同一 HTML 阅读模板；不作为识别准确率证据。

没有进行低配性能实测、跨平台验收、超大收藏夹压力测试或逐字准确率测评。当前以 Windows x64 测试版发布。

## 下载与使用

下载 [sd-bilibili-knowledge-library-0.2.1.zip](https://github.com/Allensen/sd-bilibili-knowledge-library/raw/refs/heads/main/downloads/sd-bilibili-knowledge-library-0.2.1.zip)，由 Agent 安装完整同名文件夹。使用方法见仓库首页。

ZIP 包含代码、Skill 指令和必要说明，不包含模型、运行缓存、用户收藏或凭据。首次执行需要联网；环境、模型与媒体的下载耗时单独计算。

安装包附带 [SHA256 校验文件](../downloads/SHA256SUMS.txt)。专用 ZIP 使用与 Skill 同名的顶层目录，包含使用说明和原创演示，可直接交给 Agent 安装。仓库的 Code → Download ZIP 下载的是整个仓库，需要将解压目录重命名为 `sd-bilibili-knowledge-library` 后安装。
