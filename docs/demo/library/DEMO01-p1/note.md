# 收藏教程后，怎样真正开始练习

> 原创演示数据；不对应真实视频或转写测评。

## 先读要点

- 先给这次练习定一个小目标。
- 跟着做完，再换一个例子试一遍。
- 保留完成的作品和解决问题的记录。

## 今天先做出一个最小结果

演示原文先把练习缩小到一件能动手的事，再围绕它找视频片段。

- 例子：学图片排版，先完成一张标题清楚的卡片。
- 写下任务，找到演示片段，再做一遍。

来源（演示时间）：00:18、00:46

**理解提示（整理归纳）：** 可以把目标写成「我今天要做出……」，检查它是否足够具体。

## 换一个例子，看看自己能不能做出来

跟做完成后换一张图片或一段文字，独立再试一遍，从卡住的位置找出需要回看的步骤。

- 沿用刚学到的方法，换掉示例素材。
- 只把实际卡住的问题记下来，再回看对应片段。

来源（演示时间）：01:17

## 把踩过的坑写成自己的操作记录

演示原文建议记录当时做了什么、哪里出错、后来怎么调整。下一次遇到相似问题时更容易查。

- 保留这次做出的作品。
- 让笔记包含自己遇到的问题和调整过程。

来源（演示时间）：01:50、02:19

## 全文（原创演示）

- 00:00 今天用一个小例子，讲讲收藏教程以后怎么开始动手。先写下你想完成的东西，再从视频里找到相关的方法。
- 00:18 不要一次给自己安排太多任务。比如学图片排版，今天先做一张标题清楚的卡片，做到这里就算完成这一轮练习。
- 00:46 把这次任务写下来，然后找到视频中对应的演示段落，跟着操作一次。遇到卡住的地方，记下问题和视频时间，方便再看。
- 01:17 跟着做完以后，换一张图片或者换一段文字，自己再试一次。这样能发现自己哪些步骤理解了，哪些地方还要回去看。
- 01:50 把刚才卡住的问题写进自己的笔记。记录自己当时做了什么、哪里不对、后来怎么调整，比只抄一句结论更方便下次查。
- 02:19 最后留下一张完成的卡片，以及这次练习的几条记录。下次可以换个小任务，继续使用这些步骤。
